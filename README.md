# 资管双智能体产品与Agent落地方案 V2.3

面向客户评审与业务演示的静态方案网站。

- 合同履约助手：单合同事实、付款、风险核查、证据与人工复核。
- 企业经营与合同洞察助手：授权合同范围内的企业分析、六维指标、合同贡献和穿透。
- 包含30个业务场景、业务交互原型、Agent工程实现设计、工具契约、提示词、开发清单与验收样本。

## 查看

网站入口为 `index.html`，适用于 GitHub Pages 分支根目录发布。无需安装依赖或构建。

- 方案：`客户演示.html`
- 独立交互原型：`业务交互原型.html`
- 完整设计：`完整产品方案.md`
- Agent实现设计：`Agent工程实现设计.md`
- 开发蓝图：`Agent开发蓝图/`
- 完整离线包：`完整方案包_V2.3.zip`

所有演示企业和金额均为虚构，业务截至日固定为2026年11月8日。网站为方案与本地交互演示，尚未连接真实资管接口或AI中台；验收样本是实施规格，不代表客户环境已验收。
